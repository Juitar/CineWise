## 为什么改

当前公共布局与认证表单中存在重复图标、Emoji 图标和手写控件：移动端底栏的三个入口使用同一影片图标，管理端侧栏及通知入口使用 Emoji，密码显示按钮没有复用 Ant Design 的密码输入框。这些实现会导致图标语义不清、不同系统显示不一致，以及密码小眼睛在输入框内不居中。

## 本次修改

- 用户端和管理端侧栏统一使用项目 SVG 图标，去除 Emoji 图标。
- 移动端底栏为首页、影片、影院和个人中心分别配置正确图标，并继续使用 antd-mobile `TabBar`。
- 登录和注册页改用 Ant Design `Input.Password`，由组件处理查看密码按钮的位置、焦点和无障碍属性。
- 注册页的验证码后缀改用 Ant Design `Button`。
- 管理端 Agent 运行记录将通用的列表、状态标签、表格和加载更多入口替换为 Ant Design 组件；保留时间线等特殊展示。

## 不做什么

- 不修改页面路由、接口、DTO、权限和业务数据。
- 不新增依赖，不重做特殊展示的 Agent 时间线。
- 不处理影院/电影列表当前未提交的改动。

- 验收：桌面与移动端导航图标含义正确；密码眼睛在输入框内垂直居中；管理端运行记录的通用控件均使用 Ant Design，且现有选中、状态和表格内容保持可用。
