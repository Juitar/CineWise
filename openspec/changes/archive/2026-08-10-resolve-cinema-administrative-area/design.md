# 设计

## 解析位置

规则放在 `content.infrastructure.provider`，只处理 NetStart 已返回的影院地址，不把 Provider 原始 JSON 泄露到其他层。

## 规则

解析器按 `cityCode` 读取本项目已支持城市的行政区名称清单，再从地址中匹配最长的已登记名称。

- 长沙支持区、长沙县以及浏阳市、宁乡市等县级市。
- 杭州支持区、县和县级市。
- 未命中时仍返回“未知区域”，不从“住宅区”“商业区”等地点名称猜测行政区。

这种方式比按单个后缀截取更稳定，也不会为未知城市或未知文本虚构区域。

## 兼容性

`CinemaContent.area` 仍为非空字段，公开 API 与数据库不变。已保存的“未知区域”不会自动修正；发布后执行一次对应城市的内容同步才会按新规则写入。

## 测试

通过 NetStart Provider 测试覆盖区、县、浏阳市、未登记地点文本和影院详情映射，确认搜索结果与详情结果使用相同规则。
