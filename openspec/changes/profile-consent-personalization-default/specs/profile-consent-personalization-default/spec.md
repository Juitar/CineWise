# Profile Consent and Preference Usage

## ADDED Requirements

### Requirement: 两个开关说明职责清楚

个人中心 SHALL 说明第一个开关控制是否允许记录和管理画像标签，第二个开关控制相关功能是否使用画像偏好。文案 MUST NOT 表示第二个开关控制画像记录或第一个开关会自动开启第二个开关。

#### Scenario: 用户查看两个开关

- **WHEN** 用户打开已同意的个人中心
- **THEN** 页面分别展示画像标签记录开关和画像偏好使用开关的职责说明

### Requirement: 两个开关保持独立

系统 SHALL 继续分别调用画像数据同意接口和画像偏好使用接口；重新开启画像数据同意后，系统 MUST NOT 自动调用画像偏好开启接口。

#### Scenario: 用户重新同意画像数据

- **WHEN** 用户重新开启画像数据同意
- **THEN** 页面只恢复画像页面读取，不自动修改画像偏好开关

### Requirement: 旧撤回事件不得清理新状态

撤回事件处理器 SHALL 在清理前读取当前同意状态；当当前状态已重新同意时，系统 MUST 记录该事件已处理并跳过偏好关闭、标签删除和缓存清理。

#### Scenario: 撤回事件晚于重新同意到达

- **WHEN** outbox 撤回事件到达且当前同意状态为已同意
- **THEN** 系统不关闭画像偏好、不删除画像标签，并保持事件幂等记录
