# 按影院查询天气工具

## 背景

现有 `getWeather` 让模型传入固定行政区名称，并限制为四个 Demo 区域。影院表已保存经纬度，该限制会使新影院无法查询天气。

## 变更范围

- 工具参数改为已登记影院的 `cinemaId`。
- 通过 D 的公开内容查询接口读取影院坐标，使用高德逆地理编码得到行政区码，再查询天气。
- 接入 B 已授权的 Agent 白名单、执行适配器和主控；工具保持只读。

## 非范围

- 不读取用户定位，不改路线、订单、确认动作、SSE 或数据库结构。

## 协作

- D 负责内容/天气实现；B 已书面授权 D 修改 Agent 注册，PR 后由 B 复核。
