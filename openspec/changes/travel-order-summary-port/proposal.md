# 订单摘要查询端口

## 背景

D 的出行任务详情需要订单与场次的最小事实。A 负责订单和 `movie_show` 权威数据，D 不能越过应用边界访问 A 的持久化层。

## 范围

- 新增同进程公开 Application Port，按字符串 `orderId` 查询当前用户的订单/场次摘要。
- 以最小 SQL 投影返回订单号、场次、影片、影院和开场时间。
- 固定参数、越权、不存在和数据库不可用语义，并提供单元与持久化验证。

## 非范围

不新增 REST、Flyway 或表；不实现 D 的任务写入、内容聚合、路线、提醒和 C 的页面。

## 验收

合法本人订单返回六个契约字段；非法输入为 100001，越权/不存在为 205001，查询依赖不可用为 305001。所有 ID 为无前导零正十进制字符串，时间为 Asia/Shanghai 带偏移 ISO 8601。
