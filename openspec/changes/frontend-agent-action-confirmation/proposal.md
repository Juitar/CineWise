# Agent 确认操作前端接入

## 背景与目标
Agent 工作区当前把确认卡显示为只读。本变更由 C 接入 B 的确认接口，并基于 PR #145 的历史消息 `runId` 恢复未知结果。

## 范围
- 校验并脱敏显示确认卡；接入确认和拒绝。
- 防止重复提交；超时、断网、5xx 和结果未知时先拉历史消息，再按所属 `runId` 查询运行。
- 补前端单测、接口夹具测试和浏览器测试。

## 非范围
不修改确认 POST、SSE、Agent run、订单、个人中心、内容同步、路线或餐饮页面。

## Owner 与验收
C 负责前端实现；B 通过 PR #145 提供历史消息 `runId`。验收时 actionId、内部参数和订单敏感字段不显示，写操作不会自动重发。
