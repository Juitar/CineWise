# 同步 MySQL 手动验证工作流到默认分支

## 背景

仓库默认分支为 `main`，而 MySQL 集成工作流仅存在于 `dev`，导致 GitHub Actions 无法从默认分支发现 `workflow_dispatch` 入口。

## 范围

- 将现行 `backend-mysql-integration.yml` 同步到 `main`。
- 保持工作流仅手动触发，不连接共享数据库，不执行部署。
- 手动运行时允许选择需要验证的目标分支或提交。

## 非范围

- 不修改业务代码、迁移 SQL 或数据库。
- 不恢复 PR 自动触发，不修改 `dev` 上的轻量化工作流策略。
- 不读取或保存生产凭据。

## Owner 与验收

- A：审查并确认工作流只使用一次性 MySQL 8.4 服务容器。
- CI 维护者：合并后针对 PR 目标提交手动运行并保存结果。
