# demo-content-v1 数据交接清单

## 用途和边界

本清单是 D 接管内容 Mock 数据后的交接证据。它沿用 A 在场次演示中已使用的 10 部影片、4 家影院；后续 D 的资源文件、Provider、测试夹具和回退数据必须以此为唯一内容清单。

- `source`：`DEMO_CONTENT`
- `sourceType`：`MOCK`
- 数据库内部 `movieId`、`cinemaId`：首次初始化时由应用生成雪花 ID；不写入本清单，重复初始化按来源 ID 查询并复用既有 ID。
- A 的票务种子只接收 `ContentSeedCatalog` 返回的实际 ID；不得维护第二份影片、影院清单。
