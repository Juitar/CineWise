# 影片列表进入选影院并购票

## 背景

`/movies` 影片卡片目前不可点击。影院方向已有 `/cinemas/:cinemaId` → `/shows?movieId=&cinemaId=`。A 已确认正在提供公开只读 `GET /api/v1/shows/available-cinemas?movieId=&page=&size=`；C 先在唯一安全链放行该精确 GET 路径，等待 A 提供最终 DTO、OpenAPI 和固定夹具后再接入前端。前端不得下载全量影院逐一探测场次，也不得新增临时 Mock。

## 目标

- 接口确认后，为 `/movies` 卡片增加可访问的详情/选影院入口。
- 新增影片可售影院页，展示影院、可售统计、来源、数据时间、过期和降级提示。
- 选择影院后只跳转到现有 `/shows?movieId={movieId}&cinemaId={cinemaId}`。
- 覆盖加载、空结果、失败、重试、404、来源异常、PC/移动端和键盘访问。

## 非目标

不改选座、建单、支付、电子票、退票和 `/shows`；不新增影片、影院、场次、价格、库存或演示购票数据；不在页面直连网络或新增请求封装。

## Owner 与前置确认

C 负责安全链白名单和后续前端；A 负责可售条件、票务聚合、最终 DTO、OpenAPI 和固定夹具；D 负责内容摘要、来源时间和公开 Application API。A 已确认路径、`movieId/page/size` 参数和匿名 GET 权限；最终 DTO、错误码、空结果、来源字段和 D 摘要边界确认前，C 不接入前端。

## 验收

确认并实现接口后，从 `/movies` 可进入选影院页并进入现有 `/shows`；无可售影院不显示购票入口；异常和来源状态提示准确。接口未确认前不声称功能已实现。
