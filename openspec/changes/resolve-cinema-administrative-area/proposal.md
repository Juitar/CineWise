# 影院行政区域解析优化

## 背景

NetStart 影院地址目前只截取第一个“区”。地址为“浏阳市镇头镇华嘉时代广场B1栋412号”时会被写入“未知区域”，而“住宅区”等普通地点文本也可能被误判为行政区。

## 本次范围

- D 在 NetStart 内容适配器中，按已支持城市的明确行政区名称识别区、县和县级市。
- 保持现有 `cinema.area`、数据库和 REST 响应字段不变。
- 补充 Provider 映射测试，并记录已存快照需要重新同步后才会更新。

## 不在本次范围

- 不修改天气查询、经纬度反向地理编码或行政区码配置。
- 不新增数据库迁移、公开接口字段或前端解析逻辑。
- 不根据模糊地址调用地理编码服务。

## 负责人和验收

- 负责人：D。
- 验收：长沙“浏阳市镇头镇...”返回“浏阳市”；区、县地址返回对应名称；未登记的地点文本仍返回“未知区域”；现有 Provider 测试通过。
