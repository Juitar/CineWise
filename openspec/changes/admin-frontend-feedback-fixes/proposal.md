# Change: 修复管理员前端表单标识与同步反馈

## Why

管理订单筛选控件缺少稳定的表单标识，浏览器与自动化测试难以准确识别字段；内容同步页面又会在请求失败或结果未知时误报“已触发成功”，可能让管理员误判任务状态。

## What Changes

- 为管理订单筛选输入、状态和日期控件补充稳定的 `id`，并为文本输入补充语义化 `name`。
- 内容同步 Hook 仅在服务端返回同步任务时向页面返回成功结果。
- 内容同步页面只在取得真实任务后显示成功提示；已知失败和结果未知均不显示成功提示。

## Scope

- Owner：A 负责管理订单筛选；C 负责管理端内容同步页面，本修复不改变双方后端契约。
- 不修改 REST、权限、数据库、Flyway、路由或同步幂等规则。

## Acceptance

- 筛选控件可通过稳定标识被浏览器与测试识别。
- 内容同步成功返回任务时提示成功，失败或结果未知时不误报。
- 前端受影响文件格式检查、定向测试和 OpenSpec 严格校验通过；完整质量门若被基线问题阻断，必须在 PR 中记录具体文件与结果。
