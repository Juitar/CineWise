## Purpose

定义 Agent 模型候选计划完成服务端校验后进入受控执行和持久化时，如何生成并使用不可由模型伪造的稳定方案标识。

## Requirements

### Requirement: 受控候选计划校验与执行
系统 SHALL 先验证模型产生的候选计划，再只执行允许的只读节点。进入执行和持久化的有效方案 MUST 使用服务器生成的稳定小写 UUID planId；候选计划提供的 planId 只可用于校验前的临时对象。模型不可借此创建写操作、绕过确认、扩大工具白名单或提供用户身份。

#### Scenario: 有效计划进入执行
- **WHEN** 候选计划通过服务端 Schema 和上下文校验
- **THEN** 系统以服务器 planId 初始化执行状态，并且只执行已登记的只读节点
