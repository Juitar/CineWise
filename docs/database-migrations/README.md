# 数据库迁移记录

本目录保存已经完成的 Flyway 专用验证库记录和共享库发布记录。迁移规则、责任边界和验证模板仍以 [数据库迁移审查与验证规范](../DATABASE_MIGRATION_REVIEW.md) 为准。

命名约定：

- `V<版本>_MIGRATION_VALIDATION_<日期>.md`：专用空 MySQL 8.4 首次迁移、重复迁移、结构和约束验证证据。
- `V<版本>_SHARED_MIGRATION_<日期>.md`：共享库发布前检查、备份恢复、执行和发布后验证证据。

本目录只保存脱敏证据，不保存 `.env`、数据库连接信息、密码、Token、私钥、备份文件或生产数据。
